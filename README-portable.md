# 小龙娘 · 使用说明

Windows 10/11（64 位）桌宠。当前只提供 Windows 版本。

## 开始使用

1. **保留整个程序文件夹**  
   请保留 `CodexPet-win32-x64` 整个目录，不要只拿走 `CodexPet.exe`。同目录的 Electron DLL、`resources` 和素材都是启动必需的。
2. **双击 `CodexPet.exe`**  
   Windows 可能提示“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。
3. **默认位置**  
   小龙娘出现在屏幕右下角。左键拖动可移动，快速松手会带出惯性并在屏幕边界反弹；单击会回应；右键打开互动菜单。
4. **退出**  
   从托盘菜单选择“退出”。只关闭窗口不会退出程序。

## 右键菜单

| 菜单项 | 说明 | 前提 |
|---|---|---|
| 打开 Codex 应用 | 自动检测并启动本机 Codex 桌面应用（开始菜单 / MSIX 包；部分版本显示为 ChatGPT） | 已安装 Codex 桌面应用 |
| 剩余额度 | 读取账号额度窗口，显示剩余百分比和重置倒计时 | 已安装并登录 Codex CLI |
| 上次用量 | 显示上一轮读取到的 Token 数 | 已安装 hooks 并成功上报 |
| 桌宠设置 | 调节重力、弹性、地面摩擦、总力度、顶部反弹，以及开机自动启动 | 无 |
| 回到初始位置 | 把桌宠移回屏幕右下角 | 无 |
| 动作 | 按分类选播动画 | 无 |
| 开机自动启动 | 勾选后登录 Windows 时自动出现，取消勾选则只在手动打开时出现 | 无 |

托盘菜单提供显示、隐藏、自动漫游、开机自动启动、工作/等待/完成/出错状态测试和退出。

## 可选：连接 Codex

- **打开 Codex 应用**：只安装 Codex CLI 不够，需要安装 Codex 桌面应用。
- **Token 气泡**：需要安装 hooks，并在 Codex CLI 的 `/hooks` 中审阅、信任。安装命令见项目 README 的“连接 Codex”。
- **剩余额度**：需要本机安装并登录 Codex CLI；读取的是账号限额窗口，不是账号信用额度。
- 不安装 hooks 也能正常使用桌宠本体。

## 设置与数据

设置文件：

```text
%APPDATA%\codex-white-pet\settings.json
```

可以右键“桌宠设置”图形化修改重力、弹性、地面摩擦、总力度和顶部反弹；保存后立即用于之后的拖动和抛掷。同一面板下方的“开机自动启动”会用 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入登录启动项，只影响当前用户；勾选状态保存在 `settings.json` 的 `autoStart` 字段里。

## 常见问题

**双击 EXE 没反应或报缺少文件？**  
确认保留的是整个 `CodexPet-win32-x64` 文件夹，而不是单独拷出来的 `CodexPet.exe`。

**Windows 提示“已保护你的电脑”？**  
点“更多信息”→“仍要运行”。这是未签名便携版的 SmartScreen 提示。

**“打开 Codex 应用”没反应？**  
需要安装 Codex 桌面应用；只装 Codex CLI 不够。部分版本的开始菜单显示名为 ChatGPT，程序会自动识别。

**“剩余额度”不可用？**  
需要本机安装并登录 Codex CLI。

**Token 气泡不显示？**  
需要先安装 hooks 并在 `/hooks` 中信任；仅运行桌宠不会自动产生用量数据。

**透明区域挡住下层窗口点击？**  
当前窗口是 360×410 的矩形命中区（顶部留出气泡空间），角色周围透明区域仍可能拦截点击；把桌宠移到不遮挡的位置即可。

**桌宠找不到？**  
从托盘菜单选择“显示桌宠”，或右键菜单“回到初始位置”。

## 卸载

1. 从托盘菜单选择“退出”。
2. 删除整个 `CodexPet-win32-x64` 程序目录。
3. 如需清除个人数据，删除 `%APPDATA%\codex-white-pet`。
4. 如果安装过 hooks，从 `%USERPROFILE%\.codex\hooks.json` 删除包含 `scripts/codex-hook.cjs` 的条目。

开发、构建、动画素材和插件说明见项目仓库的 `README.md`。
